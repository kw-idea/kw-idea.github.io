2025년 2월 24일 학위수여식에서 심현, 황규민 등 총 2명의 연구원이 석사학위를 수여받았다.

두 연구원은 광운대학교 대학원 인공지능응용학과 석사과정을 성공적으로 이수하며, 생성형 인공지능 및 비전-언어 모델 분야에서 의미 있는 연구 성과를 도출하였다.

심현 연구원은 「경량 언어 모델의 코드 환각 완화를 위한 멀티 에이전트 협업 시스템 개발」(A Multi-Agent Collaborative Framework for Mitigating Code Hallucination in Lightweight Language Models) 을 통해, 생성형 언어 모델에서 발생하는 코드 환각(code hallucination) 문제를 실증적으로 분석하고 이를 완화하기 위한 멀티 에이전트 시스템(MAS) 구조를 제안하였다.

황규민 연구원은 「객체 분할 및 데이터 증강을 통한 합성 이미지 검색 성능 향상」(Improving Composed Image Retrieval Performance through Object Segmentation and Data Augmentation) 을 통해, Composed Image Retrieval(CIR) 환경에서 이미지 전처리 방식이 검색 성능에 미치는 영향을 체계적으로 분석하였다.
